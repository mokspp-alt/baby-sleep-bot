# Бот сна малыша

Telegram-бот для учёта сна ребёнка. Родители говорят голосовым, когда малыш проснулся
и уснул, а бот по возрасту рассчитывает дневной сон и отбой и заранее о них напоминает.

## Что умеет

- **Голосовые сообщения.** «Проснулся», «уснула двадцать минут назад», «легли на ночь
  в половине девятого». Бот показывает, что расслышал, и записывает отметку.
- **Вопросы голосом или текстом:** «когда ему засыпать?», «во сколько отбой?»,
  «сколько он спал?». Бот отвечает, когда следующий сон и сколько до него осталось.
- **Анкета при первом запуске**, на которую тоже можно отвечать голосом: имя, пол, возраст
  (или дата рождения), сколько раз ребёнок сейчас спит днём, во сколько обычно встаёт,
  город (для часового пояса). Если сказать сразу «Маша, девочка, два года», лишние
  вопросы бот пропустит. Пройти анкету заново: `/setup`.
- **Кнопки** «☀️ Проснулись» / «😴 Уснули» и обычный текст: «проснулся в 6:50».
- **Свободный диалог через Claude Sonnet 5.5** (если задан `ANTHROPIC_API_KEY`). Писать
  можно как угодно и о чём угодно: «сегодня Лёва плохо спал и проснулся в 8:20», «сколько гулять
  зимой?». Данные бот меняет только в ключевых моментах:
  - записывает подъёмы и засыпания, исправляет и удаляет ошибочные отметки;
  - назначает время дневного сна или отбоя на сегодня («сегодня уложим в 20:30»), и
    напоминания приходят к этому времени;
  - меняет данные ребёнка и настройки («напоминай за 15 минут»).

- **Фото и файлы** (нужен Claude): скриншоты других приложений, фото дневника сна,
  выписки и анализы (PDF), таблицы Excel, текстовые файлы и CSV. Бот извлекает данные,
  объясняет их и отвечает на вопрос из подписи. Одну-две свежие отметки сна он записывает
  сразу, а журнал за несколько дней сначала перечисляет и спрашивает, записать ли.

  Если API недоступен, бот разбирает сообщения по правилам. Кнопки работают
  без Claude: так быстрее и бесплатно.
- **План дня** от времени подъёма: когда дневной сон и когда отбой. После реального
  дневного сна отбой пересчитывается. Если дневной сон пропущен, отбой будет раньше.
- **Напоминания:** за N минут до сна (по умолчанию 30) и в момент укладывания. Если дневной
  сон затянулся, бот подскажет разбудить. Если к 08:30 подъём не отмечен, бот спросит.
- **Нормы по возрасту** от 4 месяцев до 4 лет. Если ребёнок спит днём не столько раз,
  сколько обычно в его возрасте (например, в 2 года уже не спит днём), бот берёт ближайшую
  норму с таким числом снов. Возраст считается по дате рождения, поэтому
  график меняется сам, когда ребёнок растёт.
- Бот сам решает, дневной это сон или ночной. Если он ошибся, это можно поправить кнопкой
  под сообщением, там же можно сдвинуть время отметки на −5…−30 минут или удалить её.
- `/today` — сон за сутки, `/week` — за неделю.

### Нормы для 2–3 лет (по умолчанию)

| | |
|---|---|
| Окно до дневного сна | 5 ч 30 мин |
| Дневной сон | 1 ч 45 мин (разбудить после 2 ч 30 мин) |
| Окно до ночного сна | 5 ч |
| Ночной сон | 10,5–11,5 ч |

Подъём в 7:00 → дневной сон 12:30–14:15 → отбой 19:15.

Нормы для всех возрастов лежат в `sleepbot/schedule.py` (`NORMS`). Это усреднённые
рекомендации, а не медицинские указания: если вашему ребёнку подходит другой ритм,
поправьте числа.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. Локально:
   ```bash
   python -m venv .venv && .venv/bin/pip install -r requirements.txt
   BOT_TOKEN=... .venv/bin/python -m sleepbot
   ```
3. На сервере с PM2 одной командой (Ubuntu 22.04+, Python 3.10+). Повторный запуск без
   токена обновляет бота:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/mokspp-alt/baby-sleep-bot/main/deploy/install.sh | BOT_TOKEN=... bash
   ```
   То же вручную:
   ```bash
   git clone <url репозитория> baby-sleep-bot && cd baby-sleep-bot
   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
   mkdir -p data && cp .env.example .env && nano .env   # вписать BOT_TOKEN
   pm2 start ecosystem.config.js && pm2 save
   pm2 logs baby-sleep-bot
   ```
   Обновление: `git pull && .venv/bin/pip install -r requirements.txt && pm2 restart baby-sleep-bot`.
   Бот работает через long polling, поэтому ему не нужны ни порт, ни домен, ни nginx.
4. Или в Docker:
   ```bash
   docker build -t baby-sleep-bot .
   docker run -d --restart=always --name sleepbot -e BOT_TOKEN=... -v sleepdata:/data baby-sleep-bot
   ```
5. Напишите боту `/start` и ответьте на вопросы анкеты — голосом или текстом.

Голосовые распознаются прямо на сервере моделью Whisper
([faster-whisper](https://github.com/SYSTRAN/faster-whisper)), ключи и платные API не нужны.
При первом запуске модель скачивается с HuggingFace (~500 МБ для `small`) и
сохраняется в `/data/models`. Модели `small` нужно около 1 ГБ RAM. На слабом сервере
поставьте `WHISPER_MODEL=base`: она хуже распознаёт, зато ей хватает ~300 МБ.

Бот должен работать постоянно, иначе напоминания не придут. Подойдёт любой VPS или
сервис, где можно запустить Docker-контейнер с постоянным диском для `/data`
(в базе SQLite хранится история).
`.env` подхватывается автоматически, если лежит в корне проекта.

### Для двоих родителей

Добавьте бота в общий чат с партнёром. Чтобы бот видел обычные сообщения и нажатия
кнопок, а не только команды, в @BotFather выполните `/setprivacy` → выберите бота → `Disable`.

## Команды

| Команда | Что делает |
|---|---|
| `/plan` | план на сегодня |
| `/today` | сон за сутки |
| `/week` | сон за неделю |
| `/undo` | удалить последнюю отметку |
| `/setup` | заполнить анкету заново |
| `/child Имя ДД.ММ.ГГГГ` | быстро задать имя и дату рождения |
| `/tz Europe/Moscow` | часовой пояс |
| `/remind 30` | за сколько минут напоминать (0 — только в момент укладывания) |
| `/morning 08:30` / `off` | спросить про подъём, если он не отмечен |

## Разработка

```bash
.venv/bin/pip install pytest
.venv/bin/python -m pytest
```

Логика расписания (`schedule.py`), разбор текста и расшифровок (`parsing.py`) и анкета
(`onboarding.py`) не зависят от Telegram и покрыты тестами, как и сквозной диалог через
`bot.handle_text`. Распознавание речи находится в `stt.py`. `bot.py` содержит обработчики и ежеминутную проверку напоминаний.
Отправленные напоминания записываются в базу, поэтому после перезапуска они не повторяются.
